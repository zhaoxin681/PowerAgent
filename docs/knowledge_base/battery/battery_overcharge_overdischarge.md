# 定义

过充和过放是指电池单体或电池包运行超出允许电压、SOC或容量边界，可能造成性能衰减和安全风险。

# 典型现象

- 充电时单体电压超过允许上限。
- 放电时单体电压低于允许下限。
- 某个单体频繁提前触发充电或放电截止条件。

# 可能原因

- SOC估计偏差或单体一致性较差。
- 充电控制、接触器或电流执行机构异常。
- 电压采样漂移、均衡能力不足或保护策略失效。

# 所需数据

- 单体电压、包电流、SOC和充放电状态。
- 充电机指令、BMS限值和接触器状态。
- 告警记录、保护触发记录和时间同步信息。

# 验证步骤

- 确认电压采样值与独立测量结果是否一致。
- 核对BMS限值、充电机指令和实际电流。
- 检查异常单体是否在多个循环中重复出现。

# 处置建议

- 达到安全边界时停止或限制充放电。
- 完成采样链路、控制链路和电芯状态复核后再恢复运行。

# 适用边界

- 正常电压范围应依据具体电芯体系和产品要求确定。
- 不能仅根据包电压排除单体过充或过放风险。
