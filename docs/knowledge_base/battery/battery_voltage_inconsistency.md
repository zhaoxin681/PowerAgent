# 定义

单体电压不一致是指串联电池包中的不同单体在相同电流和相近环境条件下，表现出明显不同的端电压或电压变化趋势。

# 典型现象

- 充放电过程中单体最大压差持续扩大。
- 某个单体比其他单体更早达到充电或放电截止电压。
- 最低电压单体或最高电压单体在多个循环中相对固定。

# 可能原因

- 单体容量、SOC或老化程度存在差异。
- 单体直流内阻或极化特性存在差异。
- 温度分布、连接电阻或采样链路存在异常。

# 所需数据

- 同步采集的单体电压、包电流和SOC数据。
- 单体温度、内阻、容量或历史循环数据。
- 采样线、连接件和电压采集模块检查结果。

# 验证步骤

- 先检查时间同步、采样跳变和传感器异常。
- 在相近SOC、电流和温度条件下比较单体电压响应。
- 结合静置、充电和放电阶段判断差异是否持续存在。

# 处置建议

- 对压差持续扩大的电池包限制高功率充放电。
- 结合均衡、容量测试和连接检查进一步定位原因。

# 适用边界

- 仅凭一次电压差异不能确认电芯故障。
- 具体告警阈值应依据产品规格和运行条件确定。
