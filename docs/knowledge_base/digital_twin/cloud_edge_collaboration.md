# 定义

云边协同通过边缘侧实时处理与云端集中训练、分析和管理实现能力分工。

# 典型现象

- 边缘计算资源不足以运行复杂模型。
- 云端更新延迟或通信中断影响模型同步。
- 云端与边缘模型版本不一致。

# 可能原因

- 模型规模、通信带宽或部署策略不匹配。
- 版本管理、回滚和完整性校验不足。
- 云端与边缘的数据分布存在差异。

# 所需数据

- 边缘设备算力、内存、延迟和能耗。
- 模型版本、发布时间和部署状态。
- 通信质量、同步记录和推理日志。

# 验证步骤

- 确认模型版本、参数和配置一致性。
- 评估边缘推理延迟及资源占用。
- 模拟通信中断和更新失败场景。

# 处置建议

- 边缘侧保留安全规则和降级能力。
- 云端更新应支持验证、灰度部署和回滚。

# 适用边界

- 实时安全控制不能完全依赖远程云端响应。
- 云端建议下发前必须满足边缘侧安全约束。
