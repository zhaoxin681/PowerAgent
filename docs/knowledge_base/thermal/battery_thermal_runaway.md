# 定义

热失控是电池内部放热反应超过散热能力并导致温度快速、自加速上升的危险状态。

# 典型现象

- 单体温度或温升速率明显异常。
- 局部热点与周围测点温差持续扩大。
- 温度异常同时伴随电压突变、绝缘异常或气体信号。

# 可能原因

- 内短路、过充、外部加热或机械损伤。
- 冷却能力不足导致热量持续积累。
- 传感器故障也可能造成虚假高温信号。

# 所需数据

- 多点温度、温升速率和环境温度。
- 单体电压、电流、SOC及冷却系统状态。
- 绝缘、烟气或其他可用安全信号。

# 验证步骤

- 检查温度信号连续性和相邻测点一致性。
- 核对冷却执行状态与实际流量或风量。
- 联合分析温度、电压、电流和绝缘信号。

# 处置建议

- 出现快速温升或多信号异常时执行安全降级或停止运行。
- 将高风险对象交由专业安全流程处置。

# 适用边界

- 单点高温不能自动等同于热失控。
- 安全动作应服从产品级保护策略和应急规范。
