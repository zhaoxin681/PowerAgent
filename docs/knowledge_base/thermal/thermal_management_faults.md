# 定义

热管理故障是指冷却、加热、换热或温度控制能力不能满足动力系统运行需求。

# 典型现象

- 最高温度或最大温差超过目标范围。
- 冷却指令存在但温度下降不明显。
- 泵、风扇、阀或压缩机状态与控制指令不一致。

# 可能原因

- 冷却液不足、气阻、堵塞或泄漏。
- 泵、风扇、阀门或压缩机执行异常。
- 温度传感器、控制逻辑或通信链路异常。

# 所需数据

- 温度测点、环境温度和负载功率。
- 泵速、风扇转速、阀位和冷却液温度。
- 控制指令、反馈状态及故障码。

# 验证步骤

- 先检查温度传感器合理性。
- 比较控制指令和执行机构反馈。
- 结合入口出口温度和流量判断换热能力。

# 处置建议

- 热管理能力不足时限制功率或停止高负荷运行。
- 按传感器、执行机构和回路顺序排查。

# 适用边界

- 温差异常可能同时受到电芯状态和工况分布影响。
- 不能只依据单个执行机构状态判断整套热管理性能。
