# 定义

充电通信异常是指BMS与充电设备之间的报文、状态或控制指令不能正常交换。

# 典型现象

- 充电握手失败或充电流程中断。
- 请求电压、电流与实际输出长时间不一致。
- 报文超时、计数器异常或状态机停滞。

# 可能原因

- 通信链路、供电、终端电阻或连接器异常。
- 报文周期、信号定义或协议版本不一致。
- BMS或充电机状态机逻辑异常。

# 所需数据

- 通信报文、时间戳和错误计数。
- BMS和充电机状态机状态。
- 请求值、允许值、实际输出及连接状态。

# 验证步骤

- 检查物理连接、供电和通信质量。
- 确认关键报文周期、计数器和校验字段。
- 沿充电状态机定位首次出现分歧的位置。

# 处置建议

- 通信状态不确定时禁止继续高功率充电。
- 保存完整报文和状态日志用于联合分析。

# 适用边界

- 通信中断不一定代表电池本体故障。
- 协议字段和超时要求应以具体接口定义为准。
